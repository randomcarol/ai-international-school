# AI 协作与能力边界

## 当前已实现

- 作者与 AI 协作完成产品探索、信息架构、交互实现、测试和迭代复盘。
- 应用用透明的文本规则处理听写差异、目标表达检测和步骤解锁。
- 学习事件以 append-only 形式保存在浏览器本地，可还原学习证据。

## 当前未实现

- 没有调用 LLM 生成课程或评价开放式回答。
- 没有实时语音识别、发音评分或对话 Agent。
- 没有把一节课的演示数据包装成完整课程体系或测评结论。

## 下一阶段

1. 先建立经过人工标注的回答与口语评测集。
2. 为 LLM 输出定义结构化 schema、证据引用与拒答边界。
3. 将模型反馈与现有透明规则并行评测，而不是直接替换基线。
4. 加入成本、延迟、安全和学习效果指标，再决定上线范围。
