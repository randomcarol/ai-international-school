# Roadmap

当前阶段只验证“一节内容、三条表达、一次跨技能迁移”的纵向闭环。下面是后续候选，不在本阶段实现。

## 建议的下一个最小阶段

做一个可重复使用的“七日复习循环”：增加 3–5 节同主题原创课程，让已学表达在新文章、新音频和短输出中再次出现；复习仍使用可解释的简单规则，并验证用户是否愿意连续回来。

## 后续候选

- 课程内容 schema、内容审核流程和小型 Library
- 更完整的复习调度，以及跨课表达关系
- 可替换的音频 provider 和人工校对的句级标记
- 用户主动开启的录音、STT 和发音反馈
- 服务端账户、数据库、跨设备同步和隐私控制
- 教师、朋友等不同校园角色承载不同语用场景
- TOEFL 与求职面试专题课程，但不把产品缩窄为题库
- 长期学习画像、可解释推荐和课程效果评估

校园自由行走、建设经营、恋爱数值、排行榜和复杂 Agent 编排继续保持低优先级，除非用户研究证明它们能直接提升学习坚持或迁移效果。
